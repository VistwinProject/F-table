# F 區 27 吋知識圖譜

獨立於 `F-wall`、`F-table` 和 `F-Ipad` 的 27 吋螢幕展示原型。開啟 [index.html](index.html) 即可預覽；不需要安裝套件。

## 展示流程

1. NFC 選定九種設備中的一種後，顯示該設備的知識圖譜，不重複桌面端的九宮格介面。
2. 關聯節點依序聚焦，圖譜保持輕微浮動；第一個節點約 3 秒後顯示右下角問答卡，之後每三個節點再顯示一次。
3. 問答卡不使用全畫面遮罩，圖譜持續可見；切換設備時立即改為新類別。

頁面內含業主提供的 9 類設備圖譜、18 則預載問答，以及 32 節點／65 關係的完整資料。**問答只是原始示範內容節錄，不是即時 AI 或即時 IoT 查詢。**其中的歷史數值與時效性敘述，正式展出前須經業主核對。

## 操作與串接

- 不帶網址參數時，點開左下角「預覽操作」即可模擬 NFC 選擇設備。
- 傳入 `?ws=<WebSocket URL>` 時，頁面嘗試接收 `snapshot`、`tag-present`、`tag-remove` 等 NFC 事件；例如 `?ws=ws%3A%2F%2Flocalhost%3A8787`。
- 現場硬體與三端同步尚未端到端驗證；本 repo 不會變更既有 F 區主畫面或 NFC server。
